# Student Grade System

This is a simple Python project that takes a student's name and marks for 5 subjects as input, and automatically calculates their final result (Total Marks, Percentage, and Grade).

# Features
- Takes the student's name as input.
- Accepts marks for 5 subjects (Java, Python, RDBMS, Web tech, CPP).
- Calculates total marks and exact percentage.
- Automatically assigns a grade (A, B, C, D, E) based on the percentage.

# Tech Stack
- Python 3

# How to Run
1. Make sure Python is installed on your computer.
2. Save the code in a file named `main.py`.
3. Open your terminal or command prompt and run:
python main.py:
